- GitHub Actions 自动更新数据

## 信息源框架

1. 事实：SEC、HKEX、公司 IR、Fed、BLS、中国/香港政府部门等
2. 热点：X、小红书（热点发现，不作为事实源）
3. 人物：政界、投资界、金融界、商界重要人物公开信息
4. 资金：13F、Form 4、13D/13G、HKEX 权益披露等公开持仓/交易披露

> AI 负责聚合、去重、分类、摘要、结构化、评分和内容化；事实必须回到一级信源核验。
